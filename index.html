Koneksi pribadi

Pengaturan

Hubungkan aplikasi ke Google Sheet Anda melalui URL Web App Apps Script.

Tempel URL deployment yang berakhiran /exec. Setiap pengguna menggunakan deployment dan Google Sheet miliknya sendiri.

Pengaturan disimpan di browser/perangkat ini. Pada perangkat lain, isi kembali URL Anda. Nama pengguna hanya label, bukan akun login.

Cara menyiapkan Google Sheets
  1. Buka Google Sheet → Extensions → Apps Script, lalu tempel Code.gs Timekeeper. Pilih fungsi setupTimekeeper dan jalankan sekali untuk menghubungkan Sheet otomatis, tanpa mengetik ID.
  2. Samakan zona waktu Sheet dengan Asia/Jakarta.
  3. Deploy sebagai Web app, Execute as: Me, akses: Anyone. Orang yang mengetahui URL dapat memanggil endpoint tersebut.
  4. Salin URL /exec, tempel di sini, lalu klik Uji koneksi.

Timekeeper di layar utama

Pasang aplikasi.

Android
Buka website di Chrome → menu ⋮ → Tambahkan ke layar utama → pilih Install jika tersedia, atau Create shortcut → konfirmasi.

iPhone / iPad
Buka website di Safari → Bagikan → Tambahkan ke Layar Utama → Tambah.

Setelah dipasang, buka melalui ikon Timekeeper. Koneksi internet tetap diperlukan untuk membaca dan menyimpan data Google Sheets.

Jika Chrome hanya menawarkan Create shortcut, pilih opsi tersebut untuk membuat ikon di layar utama. Dukungan pemasangan ditentukan browser.
